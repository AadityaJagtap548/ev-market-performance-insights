ABOUT THIS PROJECT

From market data
to clearer questions.

This project brings together EV sales, product specifications, battery attributes, manufacturing locations and customer ratings in an interactive Tableau experience.

Battery technologies covered include LFP, NMC, NCA, Sodium-Ion and Solid-State. The workbook’s measures and filters are available directly in each embedded view.

Use the visualizations as an exploratory view of the supplied dataset. The figures describe that dataset and should not be treated as a complete census of the global EV market.
